# Clasificación de sentimientos. LLM vs Machine learning clásico

## Instalación

```bash
# Clonar el repositorio
$ git clone https://github.com/sergio-strazzacappa/llm-vs-lm
$ cd llm-vs-lm

# Crear un entorno virtual
$ mkdir .venv
$ python3 -m venv .venv

# Activar el entorno virtual
$ source ./.venv/bin/activate

# Instalar dependencias
$ pip -r requirements.txt
```
